THE PLATFORM

Your identity. Your ecosystem.

HB ID separates sign-in from individual websites, with standards-based authentication and registered applications.

🪪

Unified accounts

Manage member identities centrally with dedicated account records and a shared sign-in experience.

🛡️

Standardized sign-in

Connect websites with OpenID Connect authorization codes, consent and verified token signatures.

🔧

Developer integrations

Register participating applications with unique client IDs and approved redirect URLs.

HOW IT WORKS

Three steps, one trusted sign-in.

1

Create an HB ID account

An administrator provisions a member account in the identity server's portal.

2

Visit a connected website

Choose “Continue with HB ID” on a properly registered partner application.

3

Approve permission

Review the requested access and sign in without sharing the HB ID password with the partner website.
